# Memory Master 2.2 – SP Sosnowo

Mobilna aplikacja do powtórek słownictwa dla klas 4–8.

## Najważniejsze funkcje
- pełny bank słownictwa budowany automatycznie z oficjalnych list Memory Master podczas wdrożenia,
- fiszki, EN→PL, PL→EN, pisownia, anagramy, prawda/fałsz, wybór kategorii,
- zadania typu „jak w arkuszu”, dobieranie par, MIX i symulacja 30 pytań,
- mini-egzamin na czas,
- logo SP Sosnowo i miniatura nauczyciela,
- PWA i działanie offline po pierwszym uruchomieniu.

Repozytorium przygotowane do wdrożenia przez GitHub Pages.
